# TNHackathon

## Run the backend

```powershell
npm run backend
```

## Run the frontend

In a second terminal:

```powershell
npm run frontend
```

Open <http://127.0.0.1:5500> in a browser. The page checks the backend at
<http://127.0.0.1:8000/api/health>.

## Run both together

Install the development helper once, then start both servers:

```powershell
npm install
npm start
```
